# MindMirror 🪞

MindMirror is a smart mood journal and analytics application built using Python, Tkinter, and MySQL.  
The application helps users track emotions, analyze mood patterns, and receive wellness suggestions through an interactive dashboard.

## ✨ Features
- Mood detection from journal entries
- Interactive dashboard UI
- Mood analytics with graphs
- Smart wellness suggestions
- Journal history tracking
- MySQL database integration

## 🛠️ Tech Stack
- Python
- Tkinter
- MySQL
- Matplotlib

## 📊 Project Highlights
- Built a responsive multi-page GUI application
- Integrated MySQL database for journal storage
- Implemented mood analysis logic using keyword detection
- Visualized emotional trends using charts and analytics
